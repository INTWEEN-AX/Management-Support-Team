# 재직증명서 자동 발급 (Google Sheets + Apps Script)

구글 스프레드시트에서 행을 선택하고 메뉴를 누르면, `재직증명서_양식.hwpx`의
**텍스트만 바꾼** 개인별 재직증명서가 드라이브에 생성되고 다운로드 링크가 뜹니다.
서버 없음 · 운영비 0원.

## 파일

| 경로 | 용도 |
|---|---|
| `재직증명서_양식.hwpx` | 원본 양식 (드라이브에 업로드해서 사용) |
| `apps-script/Code.gs` | 스프레드시트에 붙여넣을 스크립트 |
| `tools/make_sample.py` | 호환성 검증용 샘플 생성기 (로컬 전용) |
| `샘플_재직증명서_홍길동.hwpx` | **먼저 열어봐야 할 검증 파일** |

## 0단계 — 먼저 이것부터 (중요)

`샘플_재직증명서_홍길동.hwpx` 를 한컴오피스로 열어보세요.

이 파일은 Apps Script의 재압축 방식(모든 항목 Deflate 압축)을 그대로 흉내 내서
만든 것입니다. 원본 양식은 `mimetype` 항목이 무압축(Stored)으로 들어있는데
Apps Script는 압축 방식을 지정할 수 없어 이 부분이 달라집니다.

- **정상적으로 열리고 내용이 홍길동/개발본부/책임연구원으로 바뀌어 있으면** → A안 그대로 진행
- **안 열리면** → Apps Script 단독으로는 불가. 파이썬 백엔드(B안)로 전환

## 1단계 — 드라이브 준비

1. `재직증명서_양식.hwpx` 를 구글 드라이브에 업로드
2. 발급 결과를 담을 폴더 하나 생성 (예: `재직증명서 발급함`)
3. 두 항목의 **링크를 복사**해 둡니다 (파일 ID는 스크립트가 링크에서 알아서 추출합니다)

## 2단계 — 스크립트 설치

1. 대상 스프레드시트에서 **확장 프로그램 → Apps Script**
2. 기본 `Code.gs` 내용을 지우고 `apps-script/Code.gs` 전체를 붙여넣기 → 저장
3. 스프레드시트를 새로고침하면 상단에 **[재직증명서]** 메뉴가 생깁니다
4. **[재직증명서] → [설정]** 에서 양식 링크와 폴더 링크를 차례로 붙여넣기
5. 최초 실행 시 권한 승인 창이 뜹니다 (드라이브 읽기/쓰기 권한 필요)

## 3단계 — 사용

발급할 사람의 **행을 아무 셀이나 선택** → **[재직증명서] → [선택한 행 발급]**
여러 행을 드래그하면 한 번에 최대 20명까지 일괄 발급됩니다.

## 시트 컬럼 매핑

현재 시트 기준으로 이렇게 대응합니다.

| 증명서 항목 | 시트 컬럼 | 비고 |
|---|---|---|
| 성  명 | `이름` | 양식 스타일에 맞춰 `홍 길 동`처럼 자동 자간 처리 |
| 주민등록번호 | `생년월일` + `성별` | **아래 주의사항 참고** |
| 주  소 | `집주소` | |
| 소  속 | `부서` | |
| 직  위 | `직위` | |
| 기  간 | `인트윈 입사년월일` | `2024년 7월 1일 ~ 2026년 현재` 형태로 자동 생성 |
| 본문 입사일 | `인트윈 입사년월일` | |
| 발급일자 | (자동) | 실행한 날짜 |

`만 나이`, `최종학력`, `이메일 주소`, `전화번호`, `경력 기간` 컬럼은 증명서에
쓰이지 않으므로 그대로 두면 됩니다. 머리글이 2단(`최종학력` 아래 학교/전공/학위/졸업년월)인
구조도 그대로 인식합니다 — 상위 5행에서 `이름` 컬럼을 찾아 머리글 행으로 잡습니다.

컬럼명이 다르면 `Code.gs` 상단 `COLUMN_ALIASES` 에 별칭만 추가하면 됩니다.

## ⚠ 주민등록번호 — 확인 필요

지금 시트에는 주민등록번호 컬럼이 없고 `생년월일`만 있습니다. 양식은
`961002-1******` 형태라 **뒷자리 첫 숫자(성별 코드)** 가 반드시 필요합니다.

스크립트는 이 순서로 처리합니다.

1. 시트에 `주민등록번호` 컬럼이 있으면 → 그 값을 자동 마스킹해서 사용 (권장)
2. 없으면 `생년월일` + `성별`(남/여) 로 `YYMMDD-N******` 생성
   (1900년대생 1/2, 2000년대생 3/4 자동 판별)
3. 둘 다 없으면 → `YYMMDD-*******` 로 두고 발급 결과 창에 경고 표시

**`성별` 컬럼 하나만 추가하시면 완전 자동화됩니다.** 공식 문서라 성별 코드를
임의로 추정하지 않도록 만들어 두었습니다.

## 알려진 제약

- **직인**: 양식에 `(인)` 텍스트만 있고 도장 이미지가 없습니다. 출력 후 날인하는 방식입니다.
  이미지 자동 삽입이 필요하면 별도 작업이 필요합니다.
- **PDF 변환**: hwpx → PDF 는 한컴오피스가 설치된 환경에서만 가능합니다.
  PDF가 필요하면 한컴에서 열어 저장하거나, 별도 구조로 재설계해야 합니다.
- **미리보기 썸네일**: 드라이브에서 보이는 썸네일 이미지(`Preview/PrvImage.png`)는
  원본 양식 그대로입니다. 파일을 열면 내용은 정상입니다.
- 양식 파일 자체를 수정하면 `Code.gs` 상단의 `TPL` 원본 문자열도 함께 고쳐야 합니다.
  (치환 대상을 하나도 못 찾으면 스크립트가 오류로 알려줍니다)
