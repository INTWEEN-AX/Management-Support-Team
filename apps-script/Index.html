처음이신가요? 4단계로 서식을 채웁니다
  1. 공고 확인 — 아래 1단계에서 입찰공고 첨부를 확인합니다.
  2. 서식 올리기 — 제안요청서·서식 파일(HWP 또는 HWPX)을 올립니다. HWP는 브라우저 안에서 HWPX로 바뀌며 원본 HWP는 서버로 보내지 않습니다.
  3. 사람·실적 고르기 — 목록에서 클릭해 담고, 아래 선택한 항목에서 빠진 값(확인 필요)을 확인하고 ✕로 뺍니다.
  4. 미리보기 → 생성 — 반영 미리보기로 어느 표 어느 칸에 들어가는지 확인한 뒤 서식 자동작성을 누릅니다. 결과는 새 파일이며 원본은 그대로입니다.

먼저 연습하려면 2단계의 예시 서식을 내려받거나 가상 데이터로 체험을 눌러 보세요. 실제 인력·실적·연락처는 쓰이지 않습니다. 제출 전에는 반드시 한컴에서 결과를 열어 확인하세요.

제안요청서 올리기

HWP · HWPX · PDF
일반 HWP 5.0~5.1 (최대 10MB)는 브라우저 안에서 HWPX로 변환합니다. 원본 HWP 파일은 서버로 보내지 않습니다. 단, 변환된 HWPX는 일반 HWPX 업로드와 같이 분석·채움을 위해 Apps Script 서버로 전송되며 드라이브에는 저장하지 않습니다. 암호·DRM·배포용·HWP 3은 지원하지 않습니다. 머리말·각주·테두리·도형 등이 달라질 수 있어 최종 제출 전 한컴에서 원본과 시각적으로 비교하세요. 실패하면 한컴에서 다른 이름으로 저장 → HWPX를 이용하세요. 한컴 HWP 일괄 변환기 안내 →
합성 예시로 먼저 확인빈 예시 서식(구조가 서로 다름)을 내려받아 올리거나, 가상 데이터로 채운 결과를 바로 볼 수 있습니다. DB·Drive에 저장하지 않습니다.
참고 제안요청서 예시 10개 예시를 누르면 파일이 업로드 목록에 바로 추가됩니다. HWP는 기존 브라우저 변환을 거치며, Drive에 복사하거나 저장하지 않습니다.
